# Medical Diary

Медицинский дневник для личного использования.

Архитектура:

- один Docker-контейнер приложения;
- база данных SQLite внутри контейнера;
- файл базы хранится в `./data/medical_diary.db`;
- резервные копии в `./backups/`;
- деплой на Synology в `/volume1/docker/medical_diary`;
- закрытый GitHub-репозиторий `medical_diary`.

Безопасность:

- `.env` не коммитится;
- секреты хранятся в `.env`;
- данные и бэкапы не публикуются в Git;
- рекомендуется закрыть сервис обратным прокси с HTTPS.

Важно:

- сервис хранит данные пользователя и не ставит диагнозы;
- медицинские данные вводятся пользователем вручную.
